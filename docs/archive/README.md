# Documentation Archive

This directory preserves material that is useful for traceability but is no longer a
current source of truth.

- `performance/`: frozen or append-only historical performance narratives;
- `plans/`: superseded planning documents retained to explain how work began;
- `local-machine/`: ignored workstation-specific notes that are not public project documentation.

Archived documents must state that they are superseded and link to the current
architecture, workflow, benchmark taxonomy, or performance report when one exists.
Do not edit historical measurements to match a newer conclusion; add a current report
and preserve the old decision in context.
