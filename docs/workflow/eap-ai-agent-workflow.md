# EAP AI Agent Workflow

This project uses a role-separated AI engineering workflow for the EAP electric-power trading platform.

## Skills

- `eap-product-scope`: challenge MVP scope and career value.
- `eap-architect-review`: review DDD boundaries, service ownership, event flow, and consistency.
- `eap-performance-review`: define TPS targets, cost model, bottlenecks, and tuning plan.
- `eap-implementation-lead`: implement accepted specs without redesigning architecture.
- `eap-qa-lead`: design integration, reliability, race-condition, and load-test validation.
- `eap-reviewer`: perform strict production-style review.
- `eap-feature-pipeline`: orchestrate the full feature workflow and produce scrum tasks.

## Command examples

```text
使用 eap-architect-review，審查三 DB 分離追 2000 TPS 的設計，不要寫 code。
```

```text
使用 eap-feature-pipeline，將「挑戰 2000 TPS 全域壓測」拆成 scrum tasks，並產出履歷證據。
```

## Resume positioning

Use this workflow as evidence of Tech Lead-style engineering practice: spec review, architecture governance, performance budgeting, implementation control, QA strategy, and production-style review.
